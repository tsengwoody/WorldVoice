# Phase 14 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- One meaning for the three main-locale policies' `enabled`, with one presenter path (C11).
- One Unicode-panel script choice helper.
- Public driver hooks for the UI.
- An NVDA-shaped `onSave`.
- Drop the role panel's duplicate saves and the shadowed `workspace_path`.

**Architecture:**
- `mainLocalePolicy.py`: every `enabled` is a config-backed property, and `EngineConsistency.preview` overrides `visible()` while a dialog is open.
- `rolePresenter.py` keeps all three flags pending.
- The panels in `speechSettingsDialog.py` use table-driven script choices, `voice_manager` and `refresh_language_detection()`.

**Tech Stack:** Python 3.11; pytest with exec-loaded panel classes (`tests/test_role_panel.py` pattern); ruff.

**Spec:** `docs/superpowers/specs/2026-10-05-phase14-ui-design.md`

## Global Constraints

- Never edit `driver/<Engine>/driver/` or `driver/sonic`; ruff scope as in earlier phases.
- User-visible behavior must not change: panel controls, order, labels, selections, saved keys, and preview/cancel/apply results. The one exception is the documented change that the engine-consistency flag follows NVDA config-profile switches.
- Translatable labels stay literal `_("…")` calls.
- `git add` explicit paths only. Never stage `docs/superpowers/finish_task.md` or `refactor.md`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Full suite `python3 -m pytest tests -q` (baseline 1646); lint gate and `ruff format --check addon`.

## Review Focus

1. **Discard after an apply in the same dialog session.** The preview must be cleared and the flags re-read from config, which apply just wrote. Task 2 tests it.
2. **A save that fails half-way.** `apply()` raises in `_edit.apply()`; no flag may be written. Engine preview stays until discard, as before. Task 2 relies on the existing failure test (`test_save_failure_writes_nothing_else_and_keeps_pending`).
3. **Unicode panel with a stored language not in the candidate list, or no candidates at all.** It selects the first item or disables the control, and an empty or disabled choice is never written. Task 1 pins it.
4. **`refresh_language_detection()` called while `uwv` is false.** It must unregister and never register. Task 3 tests it.
5. **`voice_manager` read after `terminate()`.** It returns `None`, and the panels' `getSynth().name != "WorldVoice"` guards still run first. Task 3 tests the property.

		if not names:

		return choice, locales
