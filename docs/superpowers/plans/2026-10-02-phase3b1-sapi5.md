# Phase 3b-1: SegmentHost Extensions and SAPI5 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend `runtime/segmentHost.py` with the shared hooks that SAPI5 and RHVoice need, then move the SAPI5 wrapper onto the host. This removes `playback_done` and fixes C2.

**Architecture:**
- **Host extensions (Task 1):**
  - `NativeRecord` gains an engine data slot (`native`) and per-record barriers.
  - The strategy may supply `admission_error(host)` and `drain(host, record)`.
  - New host methods: two-phase close (`close` / `wait_consumers`) with nested consumers, `abandon` (no handoff wait), and `reset()`, which rebuilds the lifecycle.
  - `request_stop` reaches a record that is still draining.
  - `_run` stops the player on a lifecycle fault before it hands off.
  - `enqueue` drops its `work` parameter, handles its edge cases, and records a segment's submit error instead of raising it.
- **SAPI5 (Task 2):**
  - `_Sapi5Strategy` maps SAPI5's request deque and outer `_speakThread` onto the host.
  - The worker retires through `host.retire`, which waits only for the handoff. `playback_done` no longer exists, so a hook fault cannot strand the worker (C2).
- Unmigrated engines (RHVoice, OneCore, VE, Cerence) and eSpeak's wrapper are untouched.

**Tech Stack:** Python 3 threading, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-10-02-phase3b1-sapi5-design.md`

## Review Focus

1. **Ordinary SAPI5 speech must not be cut off.** If a later edit makes ordinary records require `idle`, the host's missing-barrier path stops the player after every utterance.
   - Ordinary records are built with `_ORDINARY_BARRIERS = {"ended", "processed"}`, because the parent owns their queue-empty idle.
   - Covered by Task 2, `test_completed_ordinary_speech_does_not_stop_the_player` (mutation M2d).
2. **Voice reload while a segment is accepted or draining.**
   - `_initTts` invalidates under host admission, and `_initWasapiAudio` calls `host.reset()` before the new worker starts. The old segment must end silently or FAILED, and the next segment must be accepted on the new lifecycle.
   - Covered by the existing `test_voice_reload_*` tests and Task 1's reset tests (M1d).
   - The reviewer should also check that `reset()` joins the old delivery thread only outside admission.
3. **NVDA cancel while the final idle is blocked.**
   - `host.cancel()` → `lifecycle.cancel` → `request_stop` must reach a record that has retired but has not been handed off.
   - Covered by the existing `test_cancel_stops_player_while_final_idle_is_blocked` and Task 1's `test_stop_reaches_a_record_that_is_still_draining` (M1f).
4. **Lock order under cancel.**
   - `_invalidateSegments` calls `host.cancel()` while holding `_threadCond`, and `stop_native` re-enters `_threadCond`. This relies on NVDA's `threading.Condition()` default `RLock` (`ref/nvda/source/synthDrivers/sapi5.py:592`).
   - `abandon` (which waits for consumers) must run after `_threadCond` is released, because `RemoteWrite` consumers take `_threadCond`.
   - The reviewer checks this by reading; no test forces the cross-thread interleaving.
5. **Hook faults after binding (C2).**
   - The worker must hand off, ordinary speech must reach native within 1 s, and `terminate()` must return within 2 s.
   - Covered by Task 2's `test_hook_fault_after_binding_does_not_strand_the_worker` (RED before migration), and on the host side by `test_hook_fault_stops_the_player_and_releases_the_worker` (M1e).
   - The fault stop must fire only on a lifecycle fault, never on a plain cancel: an existing eSpeak test forbids stopping the player for a queued cancel.

**Files:**
- Modify: `addon/synthDrivers/WorldVoice/runtime/segmentHost.py`
- Modify: `addon/synthDrivers/WorldVoice/runtime/segmentLifecycle.py` (read-only `fault` property)
- Modify: `tests/test_segment_host.py` (16 new tests; `new_record()` replaces `new_record(None)`)
- Modify: `tests/test_espeak_segment_drain.py` (`queue_then_hold` forwards `(commands, operation=None, **kwargs)`)

**Interfaces:**
- Consumes: the phase 3a host (`SegmentHost`, `NativeRecord`, `NativeStrategy`, `LeasedPlayer`).
- Produces (Task 2 relies on these exact names):
  - `NativeRecord`:
    - `native: object | None = None`: engine data.
    - `admitting: bool = True`: False after `close`.
    - `barriers`: built from the record's own barrier set.
  - Optional strategy hooks:
    - `admission_error(host) -> Exception | None`: `speak_segment` rejects with it before acceptance.
    - `drain(host, record) -> None`: runs in `wait_playback_drained` before the barrier check while the work is valid and has no error. It may run more than once.
      - If it raises, the host records the error, fails the segment and stops the player.
      - If it records an error, the host fails the segment.
  - Changed methods:
    - `host.enqueue(commands, operation=None, *, barriers=None, native=None) -> None`:
      - Ordinary speech: control errors and submit errors are raised.
      - Segments: submit errors are recorded, then the record is abandoned.
    - `host.new_record(operation=None, *, barriers=None, native=None) -> NativeRecord`.
    - `host.consumer(record)`: refuses a closed record, except a nested entry from the thread whose `callback_record()` is that record.
  - New methods:
    - `host.close(record)`.
    - `host.wait_consumers(record)`.
    - `host.abandon(record)`: closes the record, waits for consumers, removes it from pending, retires its producer and sets `retired`. It does not wait for the handoff and is idempotent.
    - `host.reset()`: invalidates, clears the control error and bookkeeping, installs a new `SegmentLifecycle`, terminates the old one, then joins its delivery thread for 1 s outside admission. It does nothing once the host has terminated.
  - `SegmentLifecycle.fault -> Exception | None` (read-only).
