# WorldVoice 用户指南

WorldVoice 是一款 NVDA 插件，支持 eSpeak、OneCore、RHVoice 及 SAPI5 等不同语音引擎角色之间的自动切换，并提供各式各样的自定义设置。用户可依照不同情境及个人偏好，轻松调整语音设置。

随着全球化的普及，人们接触多国文字内容的机会也越来越多。无论是学习教材还是休闲阅读，我们经常可以看到不同语言混合使用，甚至在同一句话中出现中英日多种语言文字的情况。

各类数字内容（例如语言教材、数理信息或文学作品）在文字结构、上下文脉络和语言混用频率上都会有所不同。使用屏幕阅读器时，能够根据内容特性与个人喜好灵活调整朗读方式，可以提升阅读质量。

## 功能特性

* 可依不同语言指定专属语音角色，让多语内容朗读时自动切换到更合适的语音。
* 各语音角色可独立设置语速、音调、音量，在不同语言间保留各自的朗读设置。
* 可切换数字朗读方式，依需求选择以数值或逐字方式读出数字。
* 可调整数字、项目、标点、中日文及东南亚文字间空格与全文朗读的停顿长度，使朗读节奏更符合使用习惯。
* 可根据 Unicode 字符自动检测语言，减少多语内容朗读时手动切换语音的需求。

## 语音角色

在 WorldVoice 的语音角色设置面板中，您可以为不同语言设置专属的语音角色。WorldVoice 会独立保存每个语音角色的语速、音调和音量等设置值，切换角色时会应用相应的设置，这项功能特别有助于阅读非母语的内容。

* 选择一个地区语言后，语音列表会显示该地区可用的语音角色。选择某个语音角色即可完成该地区与语音角色的对应关系。
* 选择语音角色后，面板中的各项设置控件会依该角色支持的设置启用或禁用，不支持的设置将无法调整。
* 选定语音角色后，语速、音调、音量滑块与语速加倍复选框等设置控件会自动切换为该角色的设置值。调整设置值只会影响当前选定的语音角色，不会改变其他语音角色的设置。

### 一致性设置

* 主要语音引擎与地区语音引擎一致：启用后，主要语音角色与地区语音角色将只能是同一个语音引擎下的语音角色。若调整主要语音角色时，发现地区语音角色原属不同语音引擎，则该地区的语音角色会恢复成未选择状态，并仅可重新选择与主要语音角色相同引擎下的语音角色。
* 主要语音角色与地区语音角色一致：启用后，主要语音角色会与其所属语言地区（例如中文语音对应 zh 地区、英文语音对应 en 地区）的语音角色保持一致。当您在 NVDA 语音设置面板更换主要语音角色时，该地区的语音角色会自动改为相同的语音；反之，在 WorldVoice 语音角色设置面板更换该地区的语音角色时，主要语音角色也会随之更换。
* 不同语音角色之间的参数设置一致：启用后，各语音角色之间的语速、音调、音量及语速加倍参数将保持一致。调整任何一个语音角色的设置值，所有其他语音角色的设置值都会同步更新。

WorldVoice 的主要语音角色是指通过 NVDA 语音设置面板设置的语音，而地区语音角色则是通过 WorldVoice 的语音角色设置面板设置的语音。

## 语音流程

语音流程设置用来控制朗读时与数字、停顿及语言处理相关的行为。语音流程面板的“作用范围”决定支持全局的设置要应用到哪些合成器：选择“所有合成器（全局）”时应用到所有合成器；选择“仅 WorldVoice 合成器”（默认）时只在 WorldVoice 中使用。

* 支持全局的语音流程：数字模式、每组位数、全局停顿、数字停顿、语音序列停顿、中日文及东南亚文字间空格停顿、全文朗读停顿、标点停顿相关设置
* 仅支持 WorldVoice 的语音流程：根据 Unicode 字符检测语言、数字语言

* 根据 Unicode 字符检测语言：启用后将根据文本的 Unicode 字符自动判断语言并切换语音角色。注意：此功能可能与 NVDA 的自动语言切换功能冲突，建议避免同时启用。
* 数字语言：选择朗读数字的语言。
  * 跟随上下文语言（默认）：数字以前后文本的语言朗读。
  * 跟随主要语言：数字以主要语言朗读，也就是文档标示的语言或主要语音角色的语言。
  * 指定语言：数字一律由该语言的语音角色朗读。
  * 数字包括全角数字（０～９）与其他 Unicode 十进制数字，例如阿拉伯－印度数字。
* 数字模式：
  * 不处理：数字保持原样。
  * 数值模式：将数字作为数值朗读，例如“12345”会读作“一万两千三百四十五”。作为千位分隔符的逗号（例如“12,345,678”）会被移除，数字以单一数值朗读；其他逗号（例如“3,14”）保留。
  * 数字模式：逐个朗读数字，例如“12345”会读作“一二三四五”。数字之间的符号（例如“12.5”、“5-3”）会以数字语言的符号名称分开读出。
  * 分组模式：从左边开始，把数字每几位分成一组朗读。每组位数（2～10，默认 3）可以在语音流程面板或语音设置面板调整；组与符号之间会按数字停顿的设置停顿。例如每组 3 位时，“12345”会读成“123”、“45”，“123.456”会读成“123”、符号名称、“456”。
* 语音停顿调整：设置下列各种停顿的长度，数值越小停顿越短，0 为不停顿。
  * 全局停顿：下列各项停顿设置的倍率。实际停顿长度为“全局停顿 ÷ 10 × 该项停顿”毫秒，例如全局停顿为 20、数字停顿为 10 时，数字的停顿为 20 毫秒。NVDA 语音设置面板中的范围为 0～100，每次调整 10；语音流程面板中显示为 0～10。
  * 数字停顿：
    * 只以空格分隔的两个数字之间会停顿，例如“123 456”。
    * 在数字模式中，每个数字之间都会停顿；在分组模式中，每组数字与符号之间会停顿。
    * 在数字模式与分组模式中，数字的前后也会停顿，例如“第3章”，即使数字与文本以相同的语言朗读。
  * 语音序列停顿：NVDA 的一段朗读常由多个项目组成，例如对象的名称、角色与状态，这个停顿加在相邻的两个项目之间。与数字前后的停顿落在同一处时，只会听到较长的那一个。
  * 中日文及东南亚文字间空格停顿：汉字、假名、注音符号、泰文、老挝文、高棉文与缅甸文书写时不以空格分隔词语，因此空格两侧都是这些文字的字符时会停顿；而韩文与拉丁字母以空格分隔词语，因此这类字符间的空格不会停顿。
  * 全文朗读停顿：使用全文朗读时，在每一段读出的文本之后停顿。
* 标点停顿设置：在指定的标点符号处停顿。
  * 启用标点停顿控制：开启后，WorldVoice 会在“标点停顿字符”中的符号处停顿；关闭时，下列标点停顿设置都不起作用。
  * 停顿位置：连续的多个标点只算一个停顿处；数字中的标点（例如“12,500”的逗号）不停顿；标点之后没有要朗读的文本时（例如句尾）也不停顿。
  * 标点停顿：每个停顿处的停顿长度。设为 0（默认）时不额外停顿，但启用标点停顿控制时，文本仍会在每个停顿处被切开，因此听起来可能与关闭时不同。与数字前后的停顿落在同一处时，只会听到较长的那一个。
  * 移除停顿位置的指定标点符号：开启后，停顿处的标点符号不会发送给语音引擎，因此不会读出；不在停顿处的标点（例如句尾）仍会保留。
  * 标点停顿字符：要停顿的符号列表。
    * 输入方式：请把符号直接连在一起输入，不要用空格分隔。
    * 空格：空格也算一个字符，加入后每个空格处都会停顿；但中日文及东南亚文字之间的空格仍按中日文及东南亚文字间空格停顿的设置停顿。
    * 全角空格与不换行空格：全角空格（U+3000）与不换行空格请不要放在列表的最前面或最后面，NVDA 重新启动后，配置文件会去掉放在这两个位置的这两种空格。

支持全局的语音流程设置可通过 NVDA 的语音设置面板或 WorldVoice 的语音流程面板进行调整。而不支持全局的语音流程设置则仅能通过 NVDA 的语音设置面板进行调整。

## Unicode 检测

这些选项用来调整 WorldVoice 在检测文本语言时，如何处理多语共用字符集。

* 语言检测时间点：决定根据 Unicode 的语言检测要在 NVDA 处理语音指令之前或之后执行，可选择“在 NVDA 处理前”或“在 NVDA 处理后”。
* 字符集所使用的语言：为 Unicode 中多种语言共用的字符集（包括拉丁字符、汉字字符、阿拉伯字符、西里尔字符、天城文字符）设置默认的语言。遇到这些字符时，WorldVoice 按下列顺序决定朗读的语言，没有安装语音的语言会被跳过：
  1. 当前朗读的语言：若这个语言本身就用这种字符书写（例如汉字之于中文、日文、韩文），就沿用。例如以日文朗读时遇到汉字，仍以日文朗读。
  2. 主要语言：若主要语言用这种字符书写，就改用主要语言。文档有标示语言时为该语言，否则为主要语音角色的语言（检测在 NVDA 之后执行且未勾选“处理字符和符号时信任语音的语言”时，NVDA 可能改用其界面语言）。
  3. 字符集所使用的语言：以上都不符合时，才使用这个设置。
  4. 若这个设置的语言没有安装语音，则改用其他用这种字符书写且已安装语音的语言。

## 注意

* 若您同时启用 NVDA 的自动语言切换与 WorldVoice 的 Unicode 检测，两者可能互相影响，建议依需求择一使用。
* 若您想停用特定的语音引擎，请在 WorldVoice 语音引擎面板中取消勾选相应的复选框。
* 若您需要使用 eSpeak、OneCore、RHVoice、SAPI5 以外的语音引擎，请额外下载相应的驱动语音包。
* 在 NVDA 2024.1 至 2025.2 上，WorldVoice 的 SAPI5 语音引擎使用 NVDA 自带的 SAPI5 驱动程序，与 WorldVoice 6.2 相同，因此 SAPI5 语音的表现与 6.2 一样。WorldVoice 自己的 SAPI5 驱动程序会等每一段 SAPI5 语音播放完毕，才开始下一段（另一个语音或停顿），只在 NVDA 2025.3 或更高版本上使用。

# WorldVoice 更新日志

## 下一版更新

* **日文与东南亚文字的空格停顿：** “中文间空格停顿”改为“中日文及东南亚文字间空格停顿”。空格两侧都是汉字（包括所有扩展区）、假名、注音符号、泰文、老挝文、高棉文或缅甸文字符时，现在都会停顿，两侧是不同文字时也一样，例如“漢字 かな”。之前的版本只在两个常用汉字之间停顿。标点停顿字符包含空格时，这些空格按中日文及东南亚文字间空格停顿而非标点停顿的设置停顿，与之前中文的情况相同。
* **数字模式与分组模式的数字前后停顿：** 在数字模式与分组模式中，数字停顿现在也会把每个数字与前后的文本分开，例如“第3章”，即使数字与文本以相同的语言朗读。与字母相邻的数字（例如“1st”、“MP3”）也会被分开。默认的数值模式不变。将数字停顿设为 0 即可关闭这个停顿（数字之间的停顿也会一起关闭）。标点停顿或语音序列停顿与数字停顿落在同一处时，只会听到较长的那一个。
* **数字默认跟随上下文语言：** 移除 Unicode 检测面板的“检测文本语言时忽略数字”选项。数字语言新增“跟随上下文语言”（默认：数字以前后文本的语言朗读）与“跟随主要语言”（数字以主要语言朗读）。之前的版本在未勾选该选项时以主要语言朗读数字；若要保持原样，请选择“跟随主要语言”。
* **连字符留在词语上：** 使用数字语言时，紧接在词语后的连字符（例如“COVID-19”）会留在词语上，不再当成负号随数字朗读。空格后的正负号（例如“-3”）仍属于数字。
* **全角与其他 Unicode 数字视为数字：** 数字语言、数字模式、数字停顿与千位分隔符规则现在也适用于全角数字与其他 Unicode 十进制数字，例如阿拉伯－印度数字。
* **西里尔字符与天城文字符所使用的语言：** Unicode 检测面板新增西里尔字符（默认俄语）与天城文字符（默认印地语）所使用的语言。之前的版本一律使用 WorldVoice 列表中该字符集第一个已安装语音的语言；默认值保持这个行为。
* **Unicode 数据更新为 18.0.0：** Unicode 检测与中日文及东南亚文字间空格停顿现在能识别 Unicode 17.0 与 18.0 新增的字符，例如中日韩统一表意文字扩展区 J 的汉字与新增的假名。这些字符的检测与空格停顿和其他汉字与假名相同。18.0 新增的小篆字符自成一种文字，不属于汉字：Unicode 检测不会因它们切换语言，也不使用空格停顿。
* **WorldVoice 会等每一段语音播放完毕：** 使用 eSpeak、OneCore、RHVoice、VE 或 Cerence 时，WorldVoice 现在会等每一段语音播放完毕，才开始下一段（另一个语音或停顿），因此上一段还没播完时，下一个语音或停顿不会提前开始。使用 SAPI5 时，在 NVDA 2025.3 或更高版本上也是如此：WorldVoice 的 SAPI5 语音引擎使用 WorldVoice 自己的 SAPI5 驱动程序，它建立在 NVDA 2025.3 推出的语音队列之上。在 NVDA 2024.1 至 2025.2 上，SAPI5 继续使用 NVDA 自带的 SAPI5 驱动程序，与 WorldVoice 6.2 相同，不做这项等待，WorldVoice 会在 NVDA 日志中写入一行相关说明。
* **说话时切换语音不再中断语音：** 例如切换应用程序时启用了使用另一个语音的配置，正在说的内容会用原来的语音说完，之后才使用新的语音。之前的版本会中断正在说的内容。

## WorldVoice 6 更新

* **改善延迟说明时的响应速度：** 停顿任务现在可以取消，可减少启用延迟字符说明时的操作延迟。
* **改善读音字典兼容性：** 读音字典现在会在 WorldVoice 语音流程前先应用。
* **调整语音流程设置的内部实现：** 重构语音流程设置处理，让行为更清晰，也更容易维护。
* **改善语音元数据处理：** 现在会区分不同引擎中重复的语音名称，并统一没有语言名称时显示的备用语言说明。
* **重构驱动架构：** 重新设计语音引擎驱动架构与加载方式，改以清单文件（manifest）自动发现驱动，取代硬编码在程序中的加载方式。
* **调整核心封装：** 重新整理核心驱动的封装方式。
* **改善 Sonic 初始化：** Sonic 现在延迟到第一次语音回调时才初始化。
* **调整任务执行的内部实现：** 任务管理器（TaskManager）现在采用基于 Future 的设计。
* **改善内建语音引擎整合：** SAPI5、OneCore 和 eSpeak 现在会继承共用的内建基类。
* **改善数字发音逻辑：** 调整数字发音与翻译逻辑。

## WorldVoice 5 更新

* **新增功能及设置面板：** 语音流程和日志记录
* **移除已弃用的功能和设置面板：** Unicode 规范化、数字-点替换以及其他过时的设置项目
* **新增语音流程功能：** 为所有合成器启用 WorldVoice 的语音流程
* **新增日志记录功能：** 捕获每个流程前后的语音序列，以便于调试
* **新增语速加倍功能：** 允许为特定语音引擎启用语速加倍
* **增强用户体验：** 改进语音引擎和日志记录对话框中的交互体验
* **修订界面文本：** 更新界面文本以统一风格

## WorldVoice 4 更新

* 将 eSpeak 引擎集成到 WorldVoice 支持的引擎中。
* 在 NVDA 的语音设置面板中增加语速加倍设置项目。
* 在 NVDA 的语音设置面板中增加语音变声设置。
* 如果当前引擎或语音支持语速加倍，NVDA 的语音设置面板将动态显示语速加倍的设置界面。
* 用户可以在 WorldVoice 的语音设置面板中为单个语音设置语速加倍。
