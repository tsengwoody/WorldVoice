# WorldVoice 使用指南

WorldVoice 是一款 NVDA 附加元件，支援 eSpeak、OneCore、RHVoice 及 SAPI5 等不同語音引擎角色之間的自動切換，並提供各式各樣的客製化設定。使用者可依照不同情境及個人偏好，輕鬆調整語音設定。

隨著全球化的普及，人們接觸多國文字內容的機會也越來越多。無論是學習教材還是休閒閱讀，我們經常可以看到不同語言混合使用，甚至在同一句話中出現中英日多種語言文字的情況。

各類數位內容（例如語言教材、數理資訊或文學作品）在文字結構、上下文脈絡和語言混用頻率上都會有所不同。使用螢幕閱讀器時，能夠根據內容特性與個人喜好靈活調整朗讀方式可以提升閱讀的品質。

## 功能特色

* 可依不同語言指派專屬語音角色，讓多語內容朗讀時自動切換到更合適的語音。
* 各語音角色可獨立設定速度、音調、音量，在不同語言間保留各自的朗讀設定。
* 可切換數字朗讀方式，依需求選擇以數值或逐字方式讀出數字。
* 可調整數字、項目、標點、中日文及東南亞文字空白與讀出全部的停頓長度，使朗讀節奏更符合使用習慣。
* 可根據 Unicode 字元自動偵測語言，減少多語內容朗讀時手動切換語音的需求。

## 語音角色

在 WorldVoice 的語音角色設定面板中，您可以為不同語言設定專屬的語音角色。WorldVoice 會獨立儲存每個語音角色的速度、音調和音量等設定值，切換角色時會套用相應的設定，這項功能特別有助於閱讀非母語的內容。

* 選擇一個地區語言後，語音列表會顯示該地區可用的語音角色。選擇某個語音角色即可完成該地區與語音角色的對應關係。
* 選擇語音角色後，面板中的各項設定控制項會依該角色支援的設定啟用或停用，不支援的設定將無法調整。
* 選定語音角色後，速度、音調、音量滑桿與加快語速核取方塊等設定控制項會自動切換為該角色的設定值。調整設定值只會影響目前選定的語音角色，不會改變其他語音角色的設定。

### 一致性設定

* 保持主要語音引擎與地區語音引擎一致：啟用後，主要語音角色與地區語音角色將只能是同一個語音引擎下的語音角色。若調整主要語音角色時，發現地區語音角色原屬不同語音引擎，則該地區的語音角色會回復成未選擇狀態，並僅可重新選擇與主要語音角色相同引擎下的語音角色。
* 保持主要語音角色與地區語音角色一致：啟用後，主要語音角色會與其所屬語言地區（例如中文語音對應 zh 地區、英文語音對應 en 地區）的語音角色保持一致。當您在 NVDA 語音設定面板更換主要語音角色時，該地區的語音角色會自動改為相同的語音；反之，在 WorldVoice 語音角色設定面板更換該地區的語音角色時，主要語音角色也會隨之更換。
* 保持不同語音角色之間的參數一致：啟用後，各語音角色之間的速度、音調、音量及加快語速參數將保持一致。調整任何一個語音角色的設定值，所有其他語音角色的設定值都會同步更新。

WorldVoice 的主要語音角色是指透過 NVDA 語音設定面板設定的語音，而地區語音角色則是透過 WorldVoice 的語音角色設定面板設定的語音。

## 語音流程

語音流程設定用來控制朗讀時與數字、停頓及語言處理相關的行為。語音流程面板的「作用範圍」決定支援全域的設定要套用到哪些合成器：選擇「所有合成器(全域)」時套用到所有合成器；選擇「僅 WorldVoice 合成器」（預設）時只在 WorldVoice 中使用。

* 支援全域的語音流程：數字模式、每組位數、全域停頓參數、數字停頓參數、項目停頓參數、中日文及東南亞文字空白停頓參數、讀出全部停頓參數、標點停頓相關設定
* 僅支援 WorldVoice 的語音流程：根據 Unicode 字元偵測語言、數字語言

* 根據 Unicode 字元偵測語言：啟用後將根據文字的 Unicode 字元自動判斷語言並切換語音角色。注意：此功能可能與 NVDA 的自動語言切換功能衝突，建議避免同時啟用。
* 數字語言：選擇朗讀數字的語言。
 * 跟隨前後文語言（預設）：數字以前後文字的語言朗讀。
 * 跟隨主要語言：數字以主要語言朗讀，也就是文件標示的語言或主要語音角色的語言。
 * 指定語言：數字一律由該語言的語音角色朗讀。
 * 數字包括全形數字（０～９）與其他 Unicode 十進位數字，例如阿拉伯－印度數字。
* 數字模式：
 * 不處理：數字保持原樣。
 * 數值模式：將數字作為數值朗讀，例如「12345」會讀作「一萬兩千三百四十五」。作為千分位的逗號（例如「12,345,678」）會被移除，數字以單一數值朗讀；其他逗號（例如「3,14」）保留。
 * 數字模式：逐字朗讀數字，例如「12345」會讀作「一二三四五」。數字之間的符號（例如「12.5」、「5-3」）會以數字語言的符號名稱分開讀出。
 * 群組模式：從左邊開始，把數字每幾位分成一組朗讀。每組位數（2～10，預設 3）可以在語音流程面板或語音設定面板調整；組與符號之間會依數字停頓參數停頓。例如每組 3 位時，「12345」會讀成「123」、「45」，「123.456」會讀成「123」、符號名稱、「456」。
* 語音停頓調整：設定下列各種停頓的長度，數值越小停頓越短，0 為不停頓。
 * 全域停頓參數：下列各項停頓參數的倍率。實際停頓長度為「全域停頓參數 ÷ 10 × 該項停頓參數」毫秒，例如全域停頓參數為 20、數字停頓參數為 10 時，數字停頓為 20 毫秒。NVDA 語音設定面板中的範圍為 0～100，每次調整 10；語音流程面板中顯示為 0～10。
 * 數字停頓參數：
  * 只以空白分隔的兩個數字之間會停頓，例如「123 456」。
  * 在數字模式中，每個數字之間都會停頓；在群組模式中，每組數字與符號之間會停頓。
  * 在數字模式與群組模式中，數字的前後也會停頓，例如「第3章」，即使數字與文字以相同的語言朗讀。
 * 項目停頓參數：NVDA 一段朗讀常由多個項目組成，例如物件的名稱、角色與狀態，這個停頓加在相鄰的兩個項目之間。與數字前後的停頓落在同一處時，只會聽到較長的那一個。
 * 中日文及東南亞文字空白停頓參數：漢字、假名、注音符號、泰文、寮文、高棉文與緬甸文書寫時不以空白分隔字詞，因此空白兩側都是這些文字的字元時會停頓；而韓文與拉丁字母以空白分隔字詞，因此這類字元間的空白不會停頓。
 * 讀出全部停頓參數：使用讀出全部（全文朗讀）時，在每一段讀出的文字之後停頓。
* 標點停頓：在指定的標點符號處停頓。
 * 啟用標點停頓控制：開啟後，WorldVoice 會在「標點停頓字元」中的符號處停頓；關閉時，下列標點停頓設定都不作用。
 * 停頓位置：連續的多個標點只算一個停頓處；數字中的標點（例如「12,500」的逗號）不停頓；標點之後沒有要朗讀的文字時（例如句尾）也不停頓。
 * 標點停頓參數：每個停頓處的停頓長度。設為 0（預設）時不額外停頓，但啟用標點停頓控制時，文字仍會在每個停頓處被切開，因此聽起來可能和關閉時不同。與數字前後的停頓落在同一處時，只會聽到較長的那一個。
 * 移除停頓位置的指定標點符號：開啟後，停頓處的標點符號不會送給語音引擎，因此不會讀出；不在停頓處的標點（例如句尾）仍會保留。
 * 標點停頓字元：要停頓的符號清單。
  * 輸入方式：請把符號直接連在一起輸入，不要用空白分隔。
  * 空白：空白也算一個字元，加入後每個空白處都會停頓；但中日文及東南亞文字之間的空白仍依中日文及東南亞文字空白停頓參數停頓。
  * 全形空白與不換行空白：全形空白（U+3000）與不換行空白請不要放在清單的最前面或最後面，NVDA 重新啟動後，設定檔會去掉放在這兩個位置的這兩種空白。

支援全域的語音流程設定可透過 NVDA 的語音設定面板或 WorldVoice 的語音流程面板進行調整。而不支援全域的語音流程設定則僅能透過 NVDA 的語音設定面板進行調整。

## Unicode 偵測

這些選項用來調整 WorldVoice 在偵測文字語言時，如何處理多語共用字元集。

* 語言偵測時間點：決定根據 Unicode 的語言偵測要在 NVDA 處理語音指令之前或之後執行，可選擇「在 NVDA 處理語音指令前」或「在 NVDA 處理語音指令後」。
* 字元集假設的語言：為 Unicode 中多種語言共用的字元集（包括拉丁字元、漢字字元、阿拉伯字元、西里爾字元、天城文字元）設定預設的語言。遇到這些字元時，WorldVoice 依下列順序決定朗讀的語言，沒有安裝語音的語言會被略過：
 1. 當前朗讀的語言：若這個語言本身就用這種字元書寫（例如漢字之於中文、日文、韓文），就沿用。例如以日文朗讀時遇到漢字，仍以日文朗讀。
 2. 主要語言：若主要語言用這種字元書寫，就改用主要語言。文件有標示語言時為該語言，否則為主要語音角色的語言（偵測在 NVDA 之後執行且未勾選「處理字元與符號時信任語音的語言」時，NVDA 可能改用其介面語言）。
 3. 字元集假設的語言：以上都不符合時，才使用這個設定。
 4. 若這個設定的語言沒有安裝語音，則改用其他用這種字元書寫且已安裝語音的語言。

## 注意

* 若您同時啟用 NVDA 的自動語言切換與 WorldVoice 的 Unicode 偵測，兩者可能互相影響，建議依需求擇一使用。
* 若您想停用特定的語音引擎，請在 WorldVoice 語音引擎面板中取消勾選相應的核取方塊。
* 若您需要使用 eSpeak、OneCore、RHVoice、SAPI5 以外的語音引擎，請額外下載相應的驅動語音包。
* 在 NVDA 2024.1 至 2025.2 上，WorldVoice 的 SAPI5 語音引擎使用 NVDA 內建的 SAPI5 驅動程式，與 WorldVoice 6.2 相同，因此 SAPI5 語音的表現和 6.2 一樣。WorldVoice 自己的 SAPI5 驅動程式會等每一段 SAPI5 語音播放完畢，才開始下一段（另一個語音或停頓），只在 NVDA 2025.3 或更新版本上使用。
* 在 NVDA 語音設定面板中，位於「語音」上方的「語音引擎」用來選擇「語音」清單與快速語音設定提供哪一個語音引擎的語音。選擇語音引擎後，會立即切換到該引擎中符合 NVDA 介面語言的語音，沒有時則切換到該引擎的第一個語音。快速語音設定的「語音」只在目前的語音引擎中循環；快速語音設定沒有語音引擎項目，要切換語音引擎請使用語音設定面板。

# WorldVoice 更新日誌

## 下一版更新

* **語音設定面板的語音引擎清單：** 在 NVDA 語音設定面板中，位於「語音」上方的「語音引擎」用來選擇「語音」清單與快速語音設定提供哪一個語音引擎的語音。選擇語音引擎後，會立即切換到該引擎中符合 NVDA 介面語言的語音，沒有時則切換到該引擎的第一個語音。快速語音設定的「語音」只在目前的語音引擎中循環；快速語音設定沒有語音引擎項目，要切換語音引擎請使用語音設定面板。語音名稱不變，因此語音字典照常適用。先前版本把所有語音引擎的語音列在同一個清單中。
* **日文與東南亞文字的空白停頓：** 「中文空白停頓參數」改為「中日文及東南亞文字空白停頓參數」。空白兩側都是漢字（包括所有擴充區）、假名、注音符號、泰文、寮文、高棉文或緬甸文字元時，現在都會停頓，兩側是不同文字時也一樣，例如「漢字 かな」。先前版本只在兩個常用中文字之間停頓。標點停頓字元包含空白時，這些空白使用中日文及東南亞文字空白停頓參數而非標點停頓參數，與先前中文的情況相同。
* **數字模式與群組模式的數字前後停頓：** 在數字模式與群組模式中，數字停頓現在也會把每個數字與前後的文字分開，例如「第3章」，即使數字與文字以相同的語言朗讀。與字母相鄰的數字（例如「1st」、「MP3」）也會被分開。預設的數值模式不變。將數字停頓參數設為 0 即可關閉這個停頓（數字之間的停頓也會一起關閉）。標點停頓或項目停頓與數字停頓落在同一處時，只會聽到較長的那一個。
* **數字預設跟隨前後文語言：** 移除 Unicode 偵測面板的「偵測語言時忽略數字」選項。數字語言新增「跟隨前後文語言」（預設：數字以前後文字的語言朗讀）與「跟隨主要語言」（數字以主要語言朗讀）。先前版本在未勾選該選項時以主要語言朗讀數字；若要維持，請選擇「跟隨主要語言」。
* **連字號留在字詞上：** 使用數字語言時，緊接在字詞後的連字號（例如「COVID-19」）會留在字詞上，不再當成負號隨數字朗讀。空格後的正負號（例如「-3」）仍屬於數字。
* **全形與其他 Unicode 數字視為數字：** 數字語言、數字模式、數字停頓與千分位規則現在也適用於全形數字與其他 Unicode 十進位數字，例如阿拉伯－印度數字。
* **西里爾字元與天城文字元假設的語言：** Unicode 偵測面板新增西里爾字元（預設俄文）與天城文字元（預設印地文）假設的語言。先前版本一律使用 WorldVoice 清單中該字元集第一個已安裝語音的語言；預設值維持這個行為。
* **Unicode 資料更新為 18.0.0：** Unicode 偵測與中日文及東南亞文字空白停頓現在認得 Unicode 17.0 與 18.0 新增的字元，例如中日韓統一表意文字擴充區 J 的漢字與新增的假名。這些字元的偵測與空白停頓和其他漢字與假名相同。18.0 新增的小篆字元自成一種文字，不屬於漢字：Unicode 偵測不會因它們切換語言，也不使用空白停頓。
* **WorldVoice 會等每一段語音播放完畢：** 使用 eSpeak、OneCore、RHVoice、VE 或 Cerence 時，WorldVoice 現在會等每一段語音播放完畢，才開始下一段（另一個語音或停頓），因此上一段還沒播完時，下一個語音或停頓不會提前開始。使用 SAPI5 時，在 NVDA 2025.3 或更新版本上也是如此：WorldVoice 的 SAPI5 語音引擎使用 WorldVoice 自己的 SAPI5 驅動程式，它建立在 NVDA 2025.3 推出的語音佇列之上。在 NVDA 2024.1 至 2025.2 上，SAPI5 繼續使用 NVDA 內建的 SAPI5 驅動程式，與 WorldVoice 6.2 相同，不做這項等待，WorldVoice 會在 NVDA 記錄檔寫入一行相關說明。
* **說話時切換語音不再中斷語音：** 例如切換應用程式時啟用了使用另一個語音的組態設定檔，正在說的內容會用原本的語音說完，之後才使用新的語音。先前版本會中斷正在說的內容。
* **在兩段語音之間暫停：** 修正在一段語音剛播完時暫停，下一段語音（另一個語音或語言）仍會繼續播放的問題。現在會保持暫停，直到恢復。
* **OneCore 說完後恢復其他音訊的音量：** 開啟自動音量調整時，OneCore 說完後其他音訊的音量現在會恢復。

## WorldVoice 6 更新

* **改善延遲說明時的回應速度：** 停頓任務現在可以取消，減少啟用延遲字元說明時的操作延遲。
* **改善讀音字典相容性：** 讀音字典現在會在 WorldVoice 語音流程前先套用。
* **調整語音流程設定的內部實作：** 重構語音流程設定處理，讓行為更清楚，也更容易維護。
* **改善語音中繼資料處理：** 現在會區分不同引擎中重複的語音名稱，並統一沒有語言名稱時顯示的備用語言說明。
* **重構驅動架構：** 重新設計語音引擎驅動架構與載入方式，改以清單檔（manifest）自動探索驅動，取代寫死在程式中的載入方式。
