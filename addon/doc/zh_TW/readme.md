# WorldVoice 使用指南

WorldVoice 是一款 NVDA 附加元件，支援 Espeak、OneCore、RHVoice 及 SAPI5 等不同語音引擎角色之間的自動切換，並提供各式各樣的客製化設定。使用者可依照不同情境及個人偏好，輕鬆調整語音設定。

隨著全球化的普及，人們接觸多國文字內容的機會也越來越多。無論是學習教材還是休閒閱讀，我們經常可以看到不同語言混合使用，甚至在同一句話中出現中英日多種語言文字的情況。

各類數位內容（例如語言教材、數理資訊或文學作品）在文字結構、上下文脈絡和語言混用頻率上都會有所不同。使用螢幕閱讀器時，能夠根據內容特性與個人喜好靈活調整朗讀方式可以提身閱讀的品質。

## 功能特色

* 可依不同語言指派專屬語音角色，讓多語內容朗讀時自動切換到更合適的語音。
* 各語音角色可獨立設定速度、音調、音量，在不同語言間保留各自的朗讀設定。
* 可切換數字朗讀方式，依需求選擇以數值或逐字方式讀出數字。
* 可調整數字、項目、中文與全文朗讀間的停頓長度，使朗讀節奏更符合使用習慣。
* 可根據 Unicode 字元自動偵測語言，減少多語內容朗讀時手動切換語音的需求。

## 語音角色

在 WorldVoice 的語音角色設定面板中，您可以為不同語言設定專屬的語音角色，並針對每個角色個別調整速度、音調和音量等參數。

WorldVoice 會獨立儲存每個語音角色的設定值，切換角色時會套用相應的設定，讓語音角色能擁有各自的速度、音調與音量，這項功能特別有助於閱讀非母語的內容。

* 選擇一個地區語言後，語音列表會顯示該地區可用的語音角色。選擇某個語音角色即可完成該地區與語音角色的對應關系。
* 選擇語音角色後，如果該角色支援變聲，將會顯示可用的變聲選項供使用者選擇。
* 選定語音角色後，速度、音調、音量滑桿，以及加快語速的核取方塊將自動調整到該角色的設定值。調整設定值只會影響當前選定的語音角色（各個語音角色擁有各自獨立的設定值）。

### 一致性設定：

* 保持主要語音引擎與地區語音引擎一致：啟用後，主要語音角色與地區語音角色將只能是同個語音引擎下的語音角色。若調整主要語音角色時，發現地區語音角色原屬不同語音引擎，則該地區的語音角色會回復成未選擇狀態，並僅可重新選擇與主要語音角色相同引擎下的語音角色。
* 保持主要語音角色與地區語音角色一致：啟用後，主要語音角色與地區語音角色將保持一致。當您調整其中一方的語音角色設定時，另一方將自動同步為相同的語音角色。
* 保持不同語音角色之間的參數一致：啟用後，各語音角色之間的速度、音調、音量及加快語速參數將保持一致。調整任何一個語音角色的設定值，所有其他語音角色的設定值都會同步更新。

主要語音角色是透過 NVDA 語音設定面板設定的，而地區語音角色則是透過 WorldVoice 的語音角色設定面板設定的。

## 語音流程

語音流程設定用來控制朗讀時與數字、停頓及語言處理相關的行為。您可依需求決定這些設定要套用到所有支援的合成器，或僅在 WorldVoice 中使用。

* 支援全域的語音流程：數字模式、項目間停頓、數字間停頓、中文間停頓、讀出全部間停頓
* 僅支援 WorldVoice 的語音流程：根據 Unicode 字元偵測語言、數字語言

* 根據 Unicode 字元偵測語言：啟用後將根據文字 Unicode 自動判斷語言地區並切換語音角色。注意：此功能可能與 NVDA 的自動語言切換功能衝突，建議避免同時啟用。
* 數字語言：選擇朗讀數字的語言。
 * 跟隨當前文字語言（預設）：數字以前後文字的語言朗讀。開啟 Unicode 偵測時，中文裡的數字由中文語音朗讀。
 * 跟隨文件主要語言：數字以主要語言朗讀，也就是文件標示的語言或主要語音角色的語言。
 * 指定語言：數字一律由該語言的語音角色朗讀。
 * 數字包括全形數字（０～９）與其他 Unicode 十進位數字，例如阿拉伯－印度數字。
* 數字模式：
 * 不處理：數字保持原樣。
 * 數值模式：將數字作為數值朗讀，例如「12345」會讀作「一萬兩千三百四十五」。作為千分位的逗號（例如「12,345,678」）會被移除，數字以單一數值朗讀；其他逗號（例如「3,14」）保留。
 * 數字模式：逐字朗讀數字，例如「12345」會讀作「一二三四五」。數字之間的符號（例如「12.5」、「5-3」）會以數字語言的符號名稱分開讀出。
 * 群組模式：從左邊開始，把數字每幾位分成一組朗讀。每組位數（2～10，預設 3）可以在語音流程面板或語音設定面板調整；組與符號之間以數字間停頓分隔。例如每組 3 位時，「12345」會讀成「123」、「45」，「123.456」會讀成「123」、符號名稱、「456」。
* 語音停頓調整：設定數字之間、項目之間、中文之間與全文朗讀之間的停頓時間，數值越小停頓越短，0 為不停頓。在數字模式與群組模式中，數字停頓也會加在每個數字的前後（數字前後有其他要朗讀的文字時，不論文字在同一個項目或相鄰的項目），例如「第3章」，即使數字與文字以相同的語言朗讀。朗讀內容的最開頭與最結尾不加這個停頓；項目間停頓落在同一處時，只會聽到較長的那一個。數值模式與「不處理」不加這個停頓；數字停頓為 0 時也不加。
* 標點停頓字元：開啟「啟用標點停頓控制」時，WorldVoice 會在這些符號處停頓。請把符號直接連在一起輸入，不要用空白分隔；空白也算一個字元，輸入後每個空白都會停頓。全形空白（U+3000）與不換行空白請不要放在清單的最前面或最後面，NVDA 重新啟動後，設定檔會把放在那裡的這兩種空白去掉。

支援全域的語音流程設定可透過 NVDA 的語音設定面板或 WorldVoice 的語音流程面板進行調整。而不支援全域的語音流程設定則僅能透過 NVDA 的語音設定面板進行調整。

## Unicode 偵測

這些選項用來調整 WorldVoice 在偵測文字語言時，如何處理多語共用字元集。

* 語言偵測時間點：決定何時根據 Unicode 的語言偵測和語言切換指令是在 NVDA 處理語音指令之前還是之後。
* 字元集假設的語言：為 unicode 中多重語言共用的字元集（包括拉丁字元、漢字字元、阿拉伯字元、西里爾字元、天城文字元）設定預設的語言。只有在當前朗讀的語言與主要語言（主要語音角色的語言，偵測在 NVDA 之後執行且未勾選「處理字元與符號時信任語音的語言」時，NVDA 可能改用其介面語言；或文件標示的語言）都不是使用該字元集且已安裝語音的語言時，才會使用這個設定；沒有安裝語音的語言會被略過。

## 注意

* 若您同時啟用 NVDA 的自動語言切換與 WorldVoice 的 Unicode 偵測，兩者可能互相影響，建議依需求擇一使用。
* 若您想停用特定的語音引擎，請在 WorldVoice 語音引擎面板中取消勾選相應的核取方塊。
* 若您需要使用 Espeak, OneCore, SAPI5 以外的語音引擎，請額外下載相應的驅動語音包。

# WorldVoice 更新日誌

## 下一版更新

* **數字模式與群組模式的數字前後停頓：** 在數字模式與群組模式中，數字停頓現在也會把每個數字與前後的文字分開，例如「第3章」，即使數字與文字以相同的語言朗讀。與字母相鄰的數字（例如「1st」、「MP3」）也會被分開。預設的數值模式不變。將數字停頓參數設為 0 即可關閉這個停頓（數字之間的停頓也會一起關閉）。標點停頓或項目間停頓與數字停頓落在同一處時，只會聽到較長的那一個。
* **數字預設跟隨文字語言：** 移除 Unicode 偵測面板的「偵測語言時忽略數字」選項。數字語言新增「跟隨當前文字語言」（預設：數字以前後文字的語言朗讀）與「跟隨文件主要語言」（數字以主要語言朗讀）。先前版本在未勾選該選項時以主要語言朗讀數字；若要維持，請選擇「跟隨文件主要語言」。
* **連字號留在字詞上：** 使用數字語言時，緊接在字詞後的連字號（例如「COVID-19」）會留在字詞上，不再當成負號隨數字朗讀。空格後的正負號（例如「-3」）仍屬於數字。
* **全形與其他 Unicode 數字視為數字：** 數字語言、數字模式、數字停頓與千分位規則現在也適用於全形數字與其他 Unicode 十進位數字，例如阿拉伯－印度數字。
* **西里爾字元與天城文字元假設的語言：** Unicode 偵測面板新增西里爾字元（預設俄文）與天城文字元（預設印地文）假設的語言。先前版本一律使用 WorldVoice 清單中該字元集第一個已安裝語音的語言；預設值維持這個行為。
* **標點停頓字元保留空白：** 標點停頓字元現在會保留輸入的每個字元，包括空白。先前版本會移除清單開頭與結尾的空白，因此只輸入一個空白時，儲存後會被清空。

## WorldVoice 6 更新

*   **改善延遲說明時的回應速度：** break task 現在可被取消，可減少啟用延遲字元說明時的操作延遲。
*   **改善讀音字典相容性：** 讀音字典現在會在 WorldVoice 語音流程前先套用。
*   **調整 pipeline settings 內部實作：** 重構語音流程設定處理，讓行為更清楚，也更容易維護。
*   **改善語音中繼資料處理：** 現在會區分不同引擎中重複的語音名稱，並正規化 fallback language descriptions。
*   **重構驅動架構：** 重新設計語音引擎驅動架構與載入方式，以 manifest-based discovery 取代 hard-coded loading。
*   **調整核心封裝：** 重新整理 core driver packaging。
*   **改善 Sonic 初始化：** Sonic 現在會在第一次語音回呼時才延遲初始化。
*   **調整 task 執行內部實作：** TaskManager 現在採用 Future-based design。
*   **改善內建語音引擎整合：** SAPI5、OneCore 和 eSpeak 現在會繼承 built-in base class。
*   **改善數字發音邏輯：** 調整數字發音與翻譯邏輯。

## WorldVoice 5 更新

*   **新增功能及設定面板：** 語音流程和日誌記錄
*   **移除已棄用的功能和設置面板：** Unicode 正規化、數字-點替換以及其他過時的設定項目
*   **新增語音流程功能：** 為所有合成器啟用 WorldVoice 的語音流程
*   **新增日誌記錄功能：** 捕獲每個流程前後的語音序列，以便於除錯
*   **新增語速加倍功能：** 允許為特定語音引擎啟用語速加倍
*   **增強使用者體驗：** 改進語音引擎和日誌記錄對話方塊中的互動體驗
*   **修訂介面文本：** 更新介面文本以統一風格

## WorldVoice 4 更新

*   將 Espeak 引擎整合到 WorldVoice 支援的引擎中。
*   在 NVDA 的語音設定面板中增加語速加倍設定項目。
*   在 NVDA 的語音設定面板中增加語音變聲設定。
*   如果當前引擎或語音支援語速加倍，NVDA 的語音設定面板將動態顯示語速加倍的設定介面。
*   使用者可以在 WorldVoice 的語音設定面板中為單個語音設定語速加倍。
